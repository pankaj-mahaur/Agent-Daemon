Agent Daemon memory keeps the corrections you give your coding agent and brings them back in later sessions, in {{hosts}}. ad keeps everything on your computer, in one SQLite file, and its memory server sends nothing anywhere. Where ad's hooks capture what you say, your corrections apply right away. Everything an agent records through the memory tools (your corrections too, on hosts without those hooks) waits for your review: until you accept it the agent sees it only when it searches, marked unreviewed, and it is never shown at session start. Notes from one project are never served in another unless you accept them as cross-project. Search results reach the agent as notes, not instructions.
